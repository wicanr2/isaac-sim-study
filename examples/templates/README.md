# 實驗紀錄範本

四份,分工不同。抄過去改成自己的欄位就能用。

| 檔案 | 記什麼 | 回答的問題 |
|---|---|---|
| `ROUNDS.md` | 每一輪改了什麼、量到什麼 | 「這個參數試過沒有?結果是什麼?」 |
| `round-entry.md` | 一段期間的敘事 | 「那幾天到底在幹嘛?當時怎麼想的?」 |
| `manifest.md` | 場景檔本身被改了什麼 | 「這個檔為什麼跟上週不一樣?怎麼回退?」 |
| `preregistration.md` | 開跑前寫死的判準 | 「這批要證明什麼?什麼算成功?什麼時候停?」 |
| `FAILURES.md` | 已證偽的假設與踩過的坑 | 「這條路有人走過嗎?」 |

用法與每個欄位的理由見 [30 驗收探針與實驗預先登記](../../docs/common/30-acceptance-probes-and-preregistration/README.md)。

**共通的一條**:結果欄寫**可驗證的量測值**,不寫感想。
「承重比 0.021」三個月後還能拿來比較,「感覺比較穩」不能。
