A. Isaac 6.0.1 受控體實測(場域 GPU 主機)

Renode + 橋接留在本機 docker,只有受控體上 GPU 主機(那台沒 docker、沒 root)。受控體協定加 TCP 傳輸,tools/remote.sh tunnel 一條 ssh -L 接上。 1. 橋接加 Tcp 受控體、fake_plant.py 加 --tcp;本機 fake 走 TCP 先綠 2. isaac_plant.py 上主機實跑,逐條回答 38 篇 §6 七件事,每條寫「量到什麼」。已知:timeStepsPerSecond 在 6.0 標 Deprecated(17 篇 §2)要讀回驗;後端已查證是 PhysX 3. C3 容差按滑移實測值重定,寫回判準與 38 篇 §1 4. 決定性:enableGPUDynamics 讀回;CSV 不同就量離散度定容差,不硬湊 5. 過的把 35/37/38 篇與腳本篇首的「未驗證」改成「實測於 …」附條件;沒過的留標記寫差在哪

B. Renode 三項修正 + 上游 PR

對象 renode-infrastructure @ add012af0…(= 1.16.1)。

項 1.16.1 現況 改成
STM32_Timer 週期 = ARR(ARR=999 跑 10000 tick → CNT 10) = ARR+1(RM0090)
STM32_Timer OC1PE/OC2PE 未實作 CCR 寫入下一個 update event 才生效
STM32_UART TC 清除後永不重設(既有內部專案實測) 送完重設 1;TCIE 時拉中斷

順序:每項一支探針(原版紅)→ i @file.cs 執行期載入修正(秒級迴圈,不建 Renode)→ 修正版綠 → fork 改碼、補上游樣式的測試 → 自建 Renode 跑上游測試(.NET 8 SDK、約 10 GB、20 分鐘以上、要網路,只做一次)。送 PR 前先問;PR 英文,附量測與 RM0090 章節;36/37 篇引用連結標「已送上游 / 已合併」。
