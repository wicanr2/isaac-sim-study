## 目標(一句話)
用 Renode 1.16.1 模擬的 STM32F4 當下位運動控制器、Isaac Sim 6.0.1 當受控體、
Rust 橋接程式串 Renode 匯流排訊號(UART / GPIO / Timer / CAN),
做出**純軟體、可在本機閉環實跑**的 HIL 教學,四篇。

## 拓撲
```
上層 ROS 2 Jazzy --cmd_vel--> Rust 橋接 --UART socket--> Renode 內 STM32F4 韌體
                                   ↕ External Control API(GPIO / TIM->CCR / run_for)
                                   ↕ IronPython hook → TCP(CAN)
                              受控體(可換):純 Python 假差速車 | Isaac Sim 6.0.1
```

## 交付物
1. `examples/hil-stm32/firmware/`  自寫開源最小韌體(C):裸機 superloop + 5 ms tick、
   USART 框包協定 + CRC16、雙輪速 PID、編碼器計數。arm-none-eabi-gcc 在 docker 建。
2. `examples/hil-stm32/renode/`    平台描述(.repl)、開機腳本(.resc)、CAN hook(IronPython)
3. `examples/hil-stm32/bridge-rs/` Rust 橋接,只用 std、零 crate、`cargo build --offline`
4. `examples/hil-stm32/plant/`     假受控體(Python)+ Isaac 6.0.1 receiver(標未驗證)
5. `docs/hil/{index.md, 35-*, 36-*, 37-*, 38-*}/README.md`
6. `build_site.py` / `check_docs.py` 的 ZONES、`docs/index.md` 篇數、根 README、version-matrix

## 篇章
- 35 HIL 是什麼;與 NVIDIA 那頁的 Jetson 型 HIL 差在哪(硬體在上位 vs 下位);
  三個時鐘(Renode 虛擬時間 / Isaac 模擬時間 / 牆鐘)為什麼是核心
- 36 STM32F4 韌體在 Renode 開機:平台描述、「型別存在 ≠ 夠用」、觀測手段(SRAM 變數 vs printer)
- 37 匯流排訊號串接:External Control 協定、UART socket、
  「Renode 把 CAN 送出去的三條路與各自碰到哪一層」一節、lockstep
- 38 驗收與失敗形態:負對照、假受控體先閉環再換 Isaac、數字怎麼量

## 工作順序(每步要有可驗訊號,紅了換方法、綠了換問題)
1. Renode 探針:External Control 的 GPIO / run_for / sysbus 讀 TIM->CCR;
   CAN 的 FrameSent 事件 + IronPython 開 TCP。**這一步決定 37 篇的設計,先做。**
2. 韌體 + 平台描述,Renode 開機走到主迴圈(用 SRAM 變數證明,不只看 printer)
3. Rust 橋接 + 假受控體閉環:cmd_vel → 輪速 → PID → duty → 受控體 → 編碼器 → 回 odom
4. 四篇正文 + 索引 + ZONES + 網站重建 + `check_docs.py` 全綠
5. Isaac 6.0.1 側程式碼(標未驗證,附驗收清單)
